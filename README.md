# DMACNS 官网

**dmacns.github.io** 是 DMACNS（去中心化多智能体商业网络系统）的官方首页。

## 关于 DMACNS

DMACNS 是全球首个面向 **Agent-to-Agent** 商业结算的去中心化协议栈，也是一个去中心化多智能体协作商业网络系统。

**使命**：让AI智能体自动、安全地做生意。坏账为零，结算毫秒级，人只需要批准。

本仓库包含 DMACNS 官方首页的静态文件：
